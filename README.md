# MediTrack – Healthcare Operations Analytics Using MySQL

## 📌 Project Overview
MediTrack is a healthcare data analysis project built using MySQL.
It explores patient registrations, doctor details, appointments, treatments, and payments to generate useful insights into healthcare operations.

## 🗂️ Database Tables
The project uses six tables:
- **patients** – Patient information and registration dates
- **doctors** – Doctor details, specialization, salary, and department
- **departments** – Department names and locations
- **appointments** – Patient appointments, dates, and status
- **treatments** – Treatment details and costs
- **payments** – Payment amounts, methods, and statuses

## 🛠️ SQL Concepts Used
- SELECT, WHERE, ORDER BY, LIMIT
- Aggregate functions: COUNT, SUM, AVG
- INNER JOIN, LEFT JOIN, AND RIGHT JOIN
- GROUP BY and HAVING
- Subqueries and Common Table Expressions (CTEs)
- Views and Stored Procedures
- Window Functions: RANK() and DENSE_RANK()

## 🎯 Project Objectives
- Analyze patient registrations and demographics
- Explore doctor salaries and department-level data
- Track appointment statuses and doctor workloads
- Summarize treatment costs and payment collections
- Practice SQL queries from beginner to advanced levels
